# Discovery

This directory contains the unstructured material produced while exploring and understanding the project.

It may include notes, experiments, comparisons, discarded ideas, questions, rough drafts, research, and other intermediate work. **It is intentionally messy.**

The purpose of this material is not to serve as final documentation, but to record the exploration and reasoning that eventually led to the project's documented decisions and specifications.

When an idea has been sufficiently explored and its conclusions are useful to the project, the relevant information should be distilled into the appropriate documentation elsewhere.

In short:

**Discovery is where we figure things out. Documentation is where we record what we figured out.**
